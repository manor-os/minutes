# Minutes roadmap

The Community repository and hosted Minutes ship independently. This page describes the public source; ideas below are not release-date commitments.

## Available in Community

- Browser recording, audio upload, and chunked live transcription
- Summaries, key points, action items, and meeting chat
- Meeting templates, transcript search, rename, tags, favorites, filters, and pagination
- Public share links, text/audio export, and browser-print PDF export
- Light/dark themes and installable web app
- Webhook notifications
- Docker deployment with API-backed or local AI processing
- Browser extension source

## Hosted features to evaluate for a Community release

- Output-language selection for notes and action items
- Newer mobile recording and upload-recovery improvements
- Quality-checked reuse of live transcripts to reduce repeated transcription

Manor task creation and MCP also depend on hosted services. Their presence online does not imply they are included in Community.

## Ideas to explore

- Clearer first-run setup and model readiness feedback
- Better recording diagnostics across mobile browsers
- Calendar integrations and additional export destinations
- Interface translations and accessibility improvements

Propose a concrete use case in [Issues](https://github.com/manor-os/minutes/issues) before starting a large implementation. See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup.
