## English

**Title:** Minutes — open-source meeting notes, with a hosted app

Minutes turns recordings into transcripts, summaries, and action items, then lets you ask follow-up questions about the meeting.

Record in your browser or upload a file. Review the key points, edit action items, search past conversations, and share or export the notes.

Two ways to start:

- **Try online:** [minutes.manorai.xyz](https://minutes.manorai.xyz/) — sign in with Manor and use the managed app.
- **Self-host:** [manor-os/minutes](https://github.com/manor-os/minutes) — MIT-licensed Community source, with Docker Compose, your own API keys, or local faster-whisper and Ollama models.

Hosted Minutes also offers 43 output-language choices for notes and actions, in-app Manor task creation, and a Manor MCP connection. These hosted integrations are not all included in the Community repository; see the README edition comparison.

We welcome feedback on recording reliability, note quality, and the self-hosting experience. Include your edition and browser when reporting an issue.

[Get started](https://github.com/manor-os/minutes#self-host) · [Contribute](https://github.com/manor-os/minutes/blob/main/CONTRIBUTING.md)

## 简体中文

**标题：** Minutes：开源会议纪要，也可直接在线使用

Minutes 将录音整理成转写、纪要和行动项，并支持继续追问会议内容。

你可以在浏览器录音或上传文件，回顾重点、编辑行动项、搜索过去的对话，以及分享或导出会议记录。

两种使用方式：

- **在线使用：**[minutes.manorai.xyz](https://minutes.manorai.xyz/)，使用 Manor 账号登录托管服务。
- **自行部署：**[manor-os/minutes](https://github.com/manor-os/minutes)，MIT 许可的 Community 源码，支持 Docker Compose、自备 API key，或运行本地 faster-whisper 与 Ollama 模型。

在线版另外提供 43 种纪要及行动项输出语言、Minutes 内创建 Manor 任务，以及 Manor MCP 连接。这些托管能力尚未全部包含在开源仓库中，具体请看 README 的版本对照。

欢迎反馈录音可靠性、纪要质量和自托管体验。提交问题时请注明版本与浏览器。
