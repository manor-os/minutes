Its 1280 × 640 PNG is below 1 MB, following [GitHub's social preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

## Screenshot provenance

The screenshots are rendered from public Community source revision `62b3409`, with fictional meeting data and simulated API responses. They contain no customer recordings or private account details. Simulated answers illustrate the interface; they are not outputs from a live model run.

The capture blocks external network requests. See the [capture script](source/capture-community.mjs) and [machine-readable provenance](source/screenshot-provenance.json).

The README uses Community captures to represent this repository. Hosted features are described separately in the edition comparison. No trial-offer graphic or unproduced demo video is included.

The black mark needs a light backdrop when used by itself. The social card already supplies one.
